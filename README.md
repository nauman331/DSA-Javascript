# DSA-Javascript

A comprehensive collection of JavaScript implementations for classic Data Structures and Algorithms (DSA), along with solutions to popular LeetCode problems and JavaScript practice exercises. This repository is designed for students, interview preparation, and anyone looking to strengthen their problem-solving skills in JavaScript.

## 📁 Project Structure

```
BASIC_DSA_QUESTIONS/
    anagram.js
    braketorderStack.js
    FindMissingNumber.js
    lengthOfLongestSubstring.js
    LinkedList.js
    maxProfit.js
    palindrome.js
    queue.js
    sortingArrays.js
    stack.js
    twoSum.js
js_practice/
    logic_zero_to_hero.js
LEETCODE/
    Move Zeroes (LeetCode #283).js
    Remove Duplicates from Sorted Array (LeetCode #26).js
    Reverse String (LeetCode #344).js
```

## 📚 Contents

### BASIC_DSA_QUESTIONS

- **anagram.js**: Check if two strings are anagrams.
- **braketorderStack.js**: Validate correct order of brackets using a stack.
- **FindMissingNumber.js**: Find the missing number in a sequence.
- **lengthOfLongestSubstring.js**: Find the length of the longest substring without repeating characters.
- **LinkedList.js**: Singly linked list implementation with insert, delete, and traverse methods.
- **maxProfit.js**: Find the maximum profit from stock prices.
- **palindrome.js**: Check if a string is a palindrome.
- **queue.js**: Queue implementation with enqueue, dequeue, and reverse operations.
- **sortingArrays.js**: Merge and sort two arrays.
- **stack.js**: Stack implementation with push, pop, peek, and clear methods.
- **twoSum.js**: Find indices of two numbers that add up to a target.

### js_practice

- **logic_zero_to_hero.js**: JavaScript basics, practice problems, and code snippets for learning and revision.

### LEETCODE

- **Move Zeroes (LeetCode #283).js**: Move all zeroes in an array to the end.
- **Remove Duplicates from Sorted Array (LeetCode #26).js**: Remove duplicates in-place from a sorted array.
- **Reverse String (LeetCode #344).js**: Reverse an array of characters in-place.

## 🚀 Getting Started

1. **Clone the repository:**
   ```
   git clone https://github.com/nauman331/DSA-Javascript.git
   cd DSA-Javascript
   ```
2. **Run any file:**
   Use Node.js to run any JavaScript file:
   ```
   node BASIC_DSA_QUESTIONS/anagram.js
   node LEETCODE/Move\ Zeroes\ \(LeetCode\ \#283\).js
   ```
